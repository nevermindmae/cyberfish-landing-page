DeKoi

A plug-in network decoy for homes and small offices.

Making real cybersecurity simple enough for everyone.

Why now?

NSM raised Norway’s cyber risk level to high in October 2026, after successful cyber attacks tripled and AI made weaknesses faster to exploit.

How does it work?

DeKoi acts as bait for a bad actor trying to access your network. A decoy with information that looks valuable, but isn’t. When someone touches it, you know immediately, and can protect your network.

Raspberry Pi 4 Model B

DeKoi is built to be attacked, safely

  • The box only connects outward. Nothing can connect in.
  • No passwords, no remote login, no web interface on the box.
  • The password an attacker types never leaves the box.
  • It only installs updates signed with our key.
  • Data stays in the EU for 90 days, and each owner sees only their own events.

DeKoi vs competitors: the empty corner

Until now, network decoys were tools for security teams.

DeKoi is built from the ground up for everyone else: plug it in, and it tells you in plain language when someone is inside.
